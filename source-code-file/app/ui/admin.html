📖 使用教程

📁 文件存储路径
收集的文件保存在飞牛「应用文件 / 云收集」目录中，按「任务ID / 提交者姓名」自动分目录存放。

📎 文件类型白名单
创建任务时可设置允许的扩展名，多个用逗号分隔（如 jpg,pdf,mp3），留空则不限制。

📋 每人提交次数
可限制每个提交者最多上传几次（0 为不限），以「姓名」为维度统计。

更多问题请参考项目文档。
