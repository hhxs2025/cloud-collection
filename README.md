# 📂 云收集 （文件收集助手1.0.1正式更名版）

一款专为飞牛 fnOS 开发的轻量级文件收集工具，帮你轻松收集团队成员的文件。

---

## 一、功能特性

| 功能 | 说明 |
|------|------|
| 📋 创建收集任务 | 设置任务名称、文件大小限制、截止时间 |
| 📤 文件提交 | 提交者填写姓名，选择文件即可上传，支持多文件 |
| 📱 二维码分享 | 每个任务自动生成二维码，扫码即可提交 |
| 🔗 一键复制链接 | 复制收集链接，分享到微信、钉钉、邮件等 |
| 🔐 管理后台 | 查看所有任务、收集进度、已提交文件 |

---

## 二、技术栈

| 组件 | 技术 |
|------|------|
| 后端 | Flask + TinyDB |
| 前端 | 原生 HTML/CSS/JavaScript |
| 数据库 | TinyDB (JSON 文件) |
| 二维码 | qrcode 库 |

---

## 三、安装方式

### 3.1应用中心手动安装（推荐）

1. 下载 cloud-collection-1.0.1.fpk
2. 登录飞牛 fnOS → 应用中心 → 手动安装
3. 选择".fpk"文件，按向导完成安装
4. 打开应用，使用默认账号登录

### 3.2使用流程
登录后台，设置公网收集地址  
　　　　↓  　
管理员创建任务 → 生成链接/二维码 → 分享给提交者  
　　　　↓  　
提交者打开链接 → 填写姓名 → 上传文件  
　　　　↓  　
管理员在后台查看收集进度和文件  

### * 默认账号 * 

| 账号 | 密码 |
|------|------|
| `admin` | `admin123` |

⚠️ * 首次登录后请及时修改密码 * 

### 3.3公网收集
- 配置好本应用的公网地址(基于DDNS+反代或内网穿透)  
- 登录应用后台，设置"公网收集地址"【后面新建收集任务时会自动生成基于“公网收集地址”的收集链接】

### 3.4文件存储
* 文件默认存储在应用目录下，安装后可自定义存储路径。
* 自定义存储路径方法：右键进入应用设置，添加“允许访问的文件夹”，编辑“存储设置-文件存储路径”
