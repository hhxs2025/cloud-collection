# 📂 文件收集助手 使用说明文档

> 版本：v1.0.0 | 适用于：飞牛 fnOS Native 应用


## 📖 简介

文件收集助手是一款专为飞牛 fnOS 开发的轻量级文件收集工具。管理员创建收集任务，生成链接或二维码，团队成员打开即可提交文件。适用于收作业、收集报名材料、汇总反馈文件等场景。

**核心特点：轻量、免维护、开箱即用。**


## ✨ 功能列表

| 功能 | 说明 |
|------|------|
| 📋 创建收集任务 | 设置任务名称、单文件大小上限、截止时间 |
| 📤 文件提交 | 提交者填写姓名，选择文件即可上传，支持一次选择多个文件 |
| 📱 二维码分享 | 每个收集任务自动生成二维码，扫码即可进入提交页面 |
| 🔗 一键复制链接 | 复制收集链接，可分享到微信、钉钉、邮件等任意渠道 |
| 🔐 管理后台 | 查看所有任务、收集进度、已提交文件列表 |
| 📊 收集记录 | 每个任务自动记录提交者、文件名、文件大小、提交时间 |

## 📖 使用流程

管理员操作：
1. 登录管理后台
2. 创建收集任务（填写任务名称、文件大小限制、截止时间）
3. 获取收集链接 / 二维码
4. 分享链接给提交者

提交者操作：
5. 打开收集链接
6. 填写姓名
7. 选择文件（支持多选）
8. 点击提交

管理员操作：
9. 在后台查看收集进度


## 👨‍💼 管理员操作指南

### 1. 登录管理后台

打开应用首页，点击「管理后台」或直接访问 /admin/login，输入管理员账号密码登录。

### 2. 创建收集任务

在管理后台首页填写以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| 收集任务名称 | 给任务起一个名称 | 2026年Q2工作总结 |
| 单文件大小限制 | 每个文件的最大大小（MB） | 50 |
| 任务截止时间 | 可选，到期后无法再提交 | 2026-05-01 18:00 |

点击「创建任务」即可生成。

### 3. 获取并分享收集链接

任务创建后，列表中会出现该任务：
- 复制链接：点击「复制」按钮，粘贴到微信、钉钉、邮件等渠道发送
- 生成二维码：点击「二维码」按钮，展示二维码图片，可扫码或保存分享

### 4. 查看收集进度

在管理后台的任务列表中查看所有任务的提交记录。


## 📤 提交者操作指南

### 提交文件步骤

1. 打开收集链接（管理员分享的链接）
2. 填写姓名
3. 选择文件（点击或拖拽，支持多选）
4. 点击「提交上传」
5. 看到「成功上传 X 个文件」提示

### 注意事项

- 单文件大小不能超过管理员设置的限制
- 支持一次选择多个文件同时上传
- 同名文件会自动重命名（加序号）

## 🐛 常见问题

### Q1：上传文件失败，提示「上传失败，请检查文件大小限制」

原因：文件大小超过管理员设置的限制（默认 50MB）。

解决：压缩文件后重新提交，或联系管理员调大文件限制。

### Q2：上传文件失败，提示「任务已过期」

原因：任务设置了截止时间，当前时间已超过截止时间。

解决：联系管理员延长截止时间或创建新任务。

### Q3：如何查看应用日志？

SSH 登录飞牛，执行：
cat /vol1/@appcenter/file-collector/var/info.log

### Q4：管理员密码忘了怎么办？

SSH 登录飞牛：
1. 查看配置文件：cat /vol1/@appcenter/file-collector/var/config.json
2. 生成新密码 SHA256：python3 -c "import hashlib; print(hashlib.sha256('新密码'.encode()).hexdigest())"
3. 编辑 config.json，替换 admin_password_hash 的值

### Q5：无法访问应用页面？

1. 检查应用是否处于「运行中」状态
2. 检查端口是否被占用：netstat -tlnp | grep 5664
3. 查看应用日志排查错误


## 🔐 安全建议

- 首次登录后立即修改 admin 密码
- 为每个任务设置合理的截止时间
- 根据实际需求设置文件大小限制
- 收集完成后及时删除任务，释放存储空间
- 如需外网访问，建议配置 HTTPS 反向代理
